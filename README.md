# 九局下半：連線棒球團隊遊戲

一款以單一球員第一人稱視角遊玩的九人合作棒球 MVP。每位玩家選擇一個守備位置，最多九人同房；不足九人時由免費、規則式 NPC 補位，不使用付費 AI 服務。

## 目前內容

- 明亮版三模式首頁：單人、多人、生涯；手機固定操作區、轉播與決策集中、能力與角色存檔獨立分頁，詳見 [介面規格](UI_LAYOUT.md)
- 最多 9 位真人玩家，每人佔用一個位置：P、C、1B、2B、3B、SS、LF、CF、RF
- 6 隊聯盟、54 名獨立球員，可在賽前切換主隊與對手
- 2026 中華職棒資料換算的虛構聯盟：中洲兄弟、統合超商獅、樂園桃猿、富利悍將、味冠龍、南鋼雄鷹；每隊 9 名可辨識但非原名的主力先發
- 2026 團隊數據能力換算：官方戰績、AVG、OBP、SLG、ERA 與部分球員成績會影響遊戲內能力值
- 2026 賽季模式：六隊完整 360 場例行賽、每隊 120 場；前三名接續五戰三勝季後挑戰賽與七戰四勝台灣大賽，單機或多人房主都能逐場推進
- 球員中心：OVR、五工具、左右投拆分、投手球種、年齡、體型、潛力與角色
- 自創球員工坊：自訂姓名、背號、球隊、守備位置、左右打投與球員模板
- My Player 建造器：13 種位置限定模板、初始總評統一 60、中文能力值、18 點起始微調、模板硬上限、即時總評與強弱項預覽
- 免費本機養成：固定 60 OVR 起步、模板上限、實戰生涯幣、等級與中文能力逐點升級；訓練與準備加成已移除
- 球員獨立生涯：一軍先發、完整九局、每季 120 場、季後賽與下一季；六類實戰專精、徽章、位置目標與分項結算，詳見 [生涯模式規則與驗證](CAREER_MODE.md)
- 多人自創角色同步：加入房間時同步本場角色能力與養成快照；每位玩家的生涯進度仍保存在自己的瀏覽器
- 角色存檔：自動保存角色、獨立球季與未完比賽；JSON 格式 2 包含獨立生涯，仍接受舊格式 1；記住目前使用的角色
- 完整統計：G、PA、AB、R、H、2B、3B、HR、RBI、BB、SO、SB、CS、AVG、OBP、SLG、OPS、ERA、FIP、WHIP、K/9、FPCT、RF/9
- 少於 9 人仍可開始，空缺位置由規則式 NPC 接管
- PeerJS 免費 CDN 連線，支援房號加入、重連與斷線後 NPC 接管
- 實戰時機操作：選完打擊策略後抓擊球點，選完投球策略後抓放球點；時機分數直接影響安打與失分機率
- 打擊、投球、守備、跑壘、得分、半局與九局結算流程
- 快速團隊訊號、守備事件、比分板、戰績與賽後總結
- GitHub Pages 靜態部署，不需要後端伺服器

## 本機啟動

在專案目錄執行：

```powershell
py -m http.server 8000
```

開啟 <http://127.0.0.1:8000/>。連線功能請使用 `http://localhost` 或 GitHub Pages 的 HTTPS 網址，不要直接以 `file://` 開啟。

## GitHub Pages

`.github/workflows/pages.yml` 會在 `main` 分支更新後自動部署。第一次推送後，請在 GitHub 專案的 **Settings → Pages** 將來源設為 **GitHub Actions**；完成後網址通常為：

```text
https://<GitHub帳號>.github.io/<儲存庫名稱>/
```
