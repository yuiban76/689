# 九局下半遊戲介面覆寫

本頁覆寫主設計系統的亮色背景，保留其大型運動標題、區塊化資訊、單一主要行動與清楚焦點。

## 視覺主題

- 場景：夜間球場、休息區戰術板、轉播計分板。
- 背景：`#07111D` 球場深藍；表面：`#0C1B27`、`#102534`。
- 主色：`#D94A36` 紅土紅；互動重點：`#F2B94B` 計分板琥珀。
- 文字：`#F5F1E8` 燈塔白；次要文字：`#A9BAC5`。
- 成功／專注：`#72D5B0`；危險：`#FF7262`。
- 標題：Bebas Neue；中文與內文：Noto Sans TC、Source Sans 3。

## 版面規則

- 頂部為固定球賽模式導覽，最多五個主要入口。
- My Player 使用「會所樞紐 → 比賽日準備 → 關鍵賽事 → 回饋與升級」結構。
- 每個畫面只突出一個主要按鈕；次要系統放在頁籤或可展開區塊。
- 大型區塊使用斜切角與底線，不使用大量相同圓角卡片。
- 數據、比分與 OVR 使用窄體運動字；敘述維持 16px 以上。

## 招牌元素

「球場燈柱」：頁面頂端的暖白光暈與細直線，讓球員卡、比分與下一場賽事像在夜場轉播中被照亮。

## 動態與可及性

- 互動 160–240ms；不做無限閃爍或裝飾性循環動畫。
- 所有按鈕至少 44px，鍵盤焦點使用琥珀外框。
- `prefers-reduced-motion` 下停用位移與卡片入場效果。
- 375、768、1024、1440px 不得水平溢出。
